# Installation

Cette page concerne RavenEmu **v0.1.0 - bêta**, Android 8.0 et plus. Aucun binaire iOS signé n'est distribué.

1. Ouvrez les [builds officiels de main](https://github.com/GhostPunishR/RavenEmu/actions/workflows/multiplateforme.yml?query=branch%3Amain+is%3Asuccess).
2. Choisissez une exécution réussie et téléchargez `ravenemu-android-beta`.
3. Extrayez l'APK du ZIP, installez-le puis importez vos propres ROM.

Un compte GitHub connecté est requis ; les artefacts sont conservés sept jours.

| Élément | Valeur |
| --- | --- |
| Nom affiché | RavenEmu |
| Identifiant Android | `com.ravenemu.preview` |
| Version | 0.1.0 - Bêta |
| Signature | Debug du build, sans clé de distribution stable configurée |

Le déplacement du dépôt conserve l'identifiant et le stockage, mais une mise à jour exige le même certificat. Avant toute désinstallation, exportez vos sauvegardes ZIP ou `.sav` ; réimportez les ROM correspondantes et les sauvegardes si nécessaire. Les archives historiques restent acceptées.

Voir [RELEASING.md](https://github.com/GhostPunishR/RavenEmu/blob/main/RELEASING.md) et [Premiers pas](https://github.com/GhostPunishR/RavenEmu/blob/main/wiki/Premiers-pas.md).
