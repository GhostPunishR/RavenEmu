# Guide pour ouvrir une issue

## Bug

Indiquez :

- la version ou le commit ;
- la console concernée ;
- les étapes de reproduction ;
- le résultat observé ;
- le résultat attendu ;
- les journaux utiles sans données privées ;
- l'appareil Android si le problème dépend du matériel.

Ne joignez aucune ROM commerciale ou sauvegarde personnelle.

## Fonctionnalité

Décrivez :

- le besoin utilisateur ;
- le comportement proposé ;
- les modules concernés ;
- les alternatives ;
- les risques de complexité ou de régression.

## Sécurité

Ne créez pas d'issue publique avec des détails exploitables. Consultez
[SECURITY.md](SECURITY.md).
