# Checklist de pull request

Cette checklist peut être reprise dans la description d'une pull request.

- [ ] Le changement est limité à un sujet cohérent.
- [ ] Le code provient d'un travail original basé sur une documentation publique.
- [ ] Aucun BIOS, ROM, sauvegarde, clé ou contenu protégé n'est ajouté.
- [ ] Les tests nécessaires sont présents.
- [ ] Les commandes Gradle utiles ont été exécutées.
- [ ] Les performances des chemins chauds ont été vérifiées si nécessaire.
- [ ] Les limites restantes sont documentées.
- [ ] Les risques de régression sont indiqués.
- [ ] La documentation est mise à jour.
- [ ] Le code de conduite et la politique de sécurité sont respectés.
