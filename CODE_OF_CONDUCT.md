# Code de conduite de RavenEmu

## Notre engagement

RavenEmu souhaite offrir un espace accueillant, sûr et respectueux à toute personne qui participe au projet, quels que soient son expérience, son identité, son origine, son âge, son apparence, son handicap, sa religion ou ses opinions techniques.

## Comportements attendus

Les membres de la communauté doivent :

- communiquer avec respect et patience ;
- formuler des critiques précises et constructives ;
- se concentrer sur les faits, le code et les besoins du projet ;
- accepter les désaccords sans attaque personnelle ;
- respecter les licences, le droit d'auteur et la vie privée ;
- aider les nouveaux contributeurs à comprendre le projet ;
- reconnaître leurs erreurs et corriger leurs propos si nécessaire.

## Comportements inacceptables

Les comportements suivants ne sont pas tolérés :

- insultes, menaces, intimidation ou harcèlement ;
- propos discriminatoires ou humiliants ;
- attaques personnelles répétées ;
- publication d'informations privées sans autorisation ;
- contenu sexuel ou violent sans rapport avec le projet ;
- perturbation volontaire des discussions ou du travail ;
- tentative d'imposer, de dissimuler ou de redistribuer du code ou du contenu protégé ;
- représailles envers une personne ayant signalé un problème de bonne foi.

## Champ d'application

Ce code s'applique aux issues, pull requests, discussions, espaces de documentation et autres échanges liés à RavenEmu. Il s'applique également lorsqu'une personne représente publiquement le projet.

## Signaler un incident

Pour un incident public simple, signalez le contenu à un mainteneur sans prolonger le conflit.

Si le signalement doit rester confidentiel, utilisez [le formulaire privé du dépôt](https://github.com/GhostPunishR/RavenEmu/security/advisories/new). Indiquez qu'il s'agit d'un signalement relatif au code de conduite et fournissez uniquement les éléments nécessaires à son examen.

N'engagez pas de débat public sur l'identité des personnes concernées. Les signalements de bonne foi seront étudiés avec discrétion.

## Application

Les mainteneurs peuvent prendre une ou plusieurs mesures selon la gravité et la répétition du comportement :

1. rappel privé des règles ;
2. avertissement formel ;
3. suppression ou verrouillage d'un contenu ;
4. limitation temporaire de la participation ;
5. exclusion définitive des espaces du projet.

Les mainteneurs s'efforcent d'entendre les personnes concernées, de protéger les informations privées et d'appliquer des mesures proportionnées. Un signalement volontairement mensonger ou destiné à harceler une personne constitue également une violation de ce code.

## Responsabilité commune

Chaque participant contribue à la qualité de la communauté. Si une discussion devient tendue, revenez aux faits, ralentissez les échanges et demandez l'aide d'un mainteneur.
